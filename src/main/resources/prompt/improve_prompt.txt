분석 결과를 바탕으로 개선이 필요한 부분만

# Strictly Prohibited (위반 시 적용 실패로 간주)
1. SEARCH/REPLACE 블록 이전에 설명, 주석, 텍스트 출력 금지. (블록 출력 완료 후 요약 섹션은 허용)
2. 변경 없는 코드 포함 금지.
3. SEARCH 블록 공백/들여쓰기 임의 변경 금지.
4. 한 번에 5개 초과 블록 출력 금지.
5. import, 클래스 선언, 필드 선언은 SEARCH 블록에 포함 금지.
6. SEARCH 블록은 반드시 함수 시그니처부터 닫는 중괄호까지만 포함할 것.
7. 파일 전체를 SEARCH 블록으로 감싸는 것 절대 금지.
