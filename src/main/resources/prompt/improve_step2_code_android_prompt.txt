# Android Best Practices
아래 Android 개발 best practice를 적극 적용하여 개선하세요.

- Architecture: ViewModel/Repository 패턴 적용, UI 로직과 비즈니스 로직 분리
- Lifecycle: lifecycleScope/viewLifecycleOwner 사용, 메모리 누수 방지
- Coroutine: suspend 함수 적절 사용, Dispatcher 명시 (IO/Main/Default), 취소 처리 추가
- Compose: Recomposition 최소화, State 관리 개선, SideEffect 적절 사용
- Room: suspend/Flow 활용, DAO 패턴 준수
- Hilt: 의존성 주입 범위 최적화
- null safety: ?. ?: let 활용, 불필요한 !! 제거
- 리소스: 하드코딩 제거, strings.xml/dimens.xml 활용
