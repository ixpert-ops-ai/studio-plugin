## MyBatis XML 전용 규칙
1. 각 블록의 `- 대상 쿼리 ID:`에 `<select>`, `<insert>`, `<update>`, `<delete>`의 `id` 값을 명확히 기입하세요.
2. 컬럼을 추가할 때, `INSERT`의 컬럼 목록과 `VALUES` 절을 모두 일관성 있게 수정하세요.
3. 파라미터 바인딩은 `#{필드명}` 형식을 사용하세요.
4. `<resultMap>` 수정이 필요하다면 해당 resultMap의 ID도 명시하세요.
5. 코드 블록은 ```xml 태그를 사용하세요.
6. 전체 쿼리를 새로 작성하여 출력하지 마세요. 반드시 기존 원본 쿼리의 전체 구조를 엄격히 유지하면서, "수정 또는 추가되는 일부분"만 코드 블록에 출력하세요.
7. 동적 SQL(`UPDATE` 구문 등) 수정 시 MyBatis 전용 태그(`<set>`, `<where>`)를 올바르게 활용하고, 쿼리문 안에 `SET` 키워드가 불필요하게 반복되지 않도록 주의하세요.
