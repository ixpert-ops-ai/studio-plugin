## Java/Kotlin 전용 규칙
1. 각 블록의 `- 대상 메서드:`에 정확한 메서드명을 기입하세요.
2. 인터페이스 구현이나 상속 시 `@Override` 어노테이션을 누락하지 마세요.
3. Interface-Impl 구조에서 Impl 클래스에 Interface에 미선언된 public 메서드를 추가하지 마세요.
4. 원본 파일에 Lombok 어노테이션(@Getter, @Setter, @Data 등)이 있는 경우, 해당 접근자를 수동으로 작성하지 마세요.
5. JPA Entity(Domain) 클래스에 필드를 추가할 경우, `@Column` 등 필수 매핑 어노테이션을 누락하지 마세요.
6. 존재하지 않는 외부 메서드 호출 시 반드시 `// FIXME: [메서드명] - [대상 클래스]에 추가 필요` 형태로 주석 처리하세요.
7. 코드 블록은 ```java 또는 ```kotlin 태그를 사용하세요.
