## JSP/HTML 전용 규칙
1. 각 블록의 `- 대상 요소:`에 수정할 HTML 요소나 속성 식별자를 명확히 기입하세요.
2. `- 삽입 위치:`에 기준이 되는 앞/뒤 요소를 구체적으로 지정하세요.
3. 표(table) 구조를 수정하여 `rowspan`이나 `colspan` 등 숫자 변경이 필요하면 반드시 명시하세요.
4. 코드 블록은 ```html 또는 ```jsp 태그를 사용하세요.
5. JavaScript 인라인 코드를 추가할 경우 ```html 블록 안에서 `<script>` 태그로 감싸서 작성하세요.
6. 달력(datepicker) 등 UI 컴포넌트를 추가할 때, 단순 HTML 태그뿐만 아니라 JS 초기화 스크립트도 누락 없이 완전하게 작성하세요.
