요구사항(SR):
설문 응답 테이블에 이메일 컬럼을 추가하여 수집하고, 관리자 설문 상세 조회 시 응답자 이메일을 앞 2자리와 도메인만 노출되도록 마스킹 처리하여 반환하도록 백엔드를 수정한다.


[Stage 0에서 확인한 사실]
- 응답자 이메일: 구체화 단계에서 survey/service·survey/dao·survey/dto 폴더를 읽어 확인했으나 이 항목을 저장하거나 조회하는 코드는 발견되지 않았습니다(읽은 범위 안의 ISSW_ADMIN_GRADE/ISSW_ADMIN_USER/ISSW_COMPANY 테이블 쿼리에서만 발견)
- 응답 저장: 읽은 범위의 매퍼(1개)에서 응답 테이블(ISSW_SURVEY_R)에 값을 받아 쓰는 INSERT/UPDATE는 발견되지 않았습니다. 이 프로젝트 밖의 다른 시스템이 응답을 저장할 수 있습니다.
- 사용자 답변(응답자 이메일): 기존 데이터 없음 → 설문 응답 테이블에 이메일 컬럼 신설·저장
위는 읽은 범위 안에서 확인한 사실이며 다른 곳에 없다는 뜻은 아닙니다. 이 사실과 어긋나게 "이미 포함되어 있다", "이미 존재한다"고 단정하지 말고, 확인하지 못한 것은 추정이라고 말하세요.
